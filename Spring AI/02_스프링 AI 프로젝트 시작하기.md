# 스프링 AI 프로젝트 시작하기

1. 사용자가 AI 애플리케이션으로 Http 요청을 보내면 
2. 스프링 AI의 핵심 구성요소인 ChatClient, ChatModel을 사용해 LLM과 통신한다.

### ChatModel
- LLM과 직접 통신하는 저수준 AP
- Spring-ai-openai-starter 같은 의존성을 추가하면 스프링 AI의 자동 구성 기능이 해당 모델에 맞는 ChatModel의 구현체를 자동으로 생성해줌.

### ChatClient
- ChatModel을 한번 더 감싸서 개발자가 프롬프트 구성, 요청 생성, 응답 처리 과정 사용하기 편하게 만든 고수준 API

## AI모델과 통신하기 위한 표준 규격 - ChatModel
- 다양한 AI 모델과 대화할 때 사용하는 표준 인터페이스.
- ChatModel을 사용하면 오픈AI, 구글, 엔트로픽 등 어떤 AI 서비스 제공업체를 사용하더라도 코드를 같은 방식으로 작성할 수 있다.
- ChatModel은 Model을 상속한 인터페이스로, AI 모델과 통신하는 기능을 공통 구조로 정의.
- AI 공급자는 이 표준 인터페이스를 기반으로 공급자별 통신 방식을 각각 구현.
